# Angie Beverages & Salads — Image Guide

Every menu item currently shows a branded placeholder (dark green gradient +
icon). To swap in a real photo, just drop a file with the **exact filename**
below into the matching folder — no code edits needed. The `<img>` tag
already points at that path; once the file exists, it fades in automatically
and the placeholder disappears.

**Specs:** JPG or PNG, ~800×600px (4:3), well-lit, consistent white/neutral
background or plating style across items so the grid feels cohesive.

If you'd rather use a different file extension (e.g. `.png` or `.webp`),
open `data.js` and change the `image` value for that item to match.
